# Pulse

A light Windows system monitor, playtime tracker and PC control panel.

**[Download the latest version](https://github.com/notyourliberal26/pulse/releases/latest)** (the `Pulse-x.y.z.zip` file under *Assets*).

1. Unzip it somewhere permanent (Documents or your Desktop).
2. Run `Pulse.exe`. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

After that, Pulse tells you when there's a new version and installs it with one click. Your history and settings are kept.

## What it does

- **Monitor:** CPU, GPU, memory, network, drives, processes, and the apps that start with Windows.
- **Playtime:** how long every app and game has been open, like Steam's playtime for everything.
- **Audio:** volumes, per-app mixer, capture card inputs, and locks that stop Windows switching devices.
- **Power:** game mode (fastest refresh rates while you play) and nap time (screens off, PC stays on).
- **Network:** speed test, ping/route test, and which apps are using the network.
- **Display:** arrange monitors, refresh rates, scale, brightness, per-screen wallpaper, saved layouts.
- **Phone control** on your home Wi-Fi, paired with a PIN.

Windows 10 or 11, 64-bit. Nothing to install: the download includes everything it needs.

This repository only hosts the downloads.
