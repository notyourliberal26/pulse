# Pulse

A light Windows system monitor, playtime tracker and PC control panel.

## Install

**[Download the installer](https://github.com/notyourliberal26/pulse/releases/latest)**: under *Assets*, click `Pulse-Setup-x.y.z.exe` and run it.

- Installs for your account, no admin needed, and adds Pulse to the Start menu.
- If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.
- To remove it: Settings → Apps → Installed apps → Pulse → Uninstall.

**Updates are automatic:** Pulse checks this page every few hours, tells you when there's a new version, and installs it with one click. Your history and settings are kept.

(The `Pulse-x.y.z.zip` file is what Pulse uses to update itself. You can also unzip it and run `Pulse.exe` directly.)

## What it does

- **Monitor:** CPU, GPU, memory, network, drives, processes, startup apps, and driver versions.
- **Playtime:** how long every app and game has been open, with FPS and temperatures per game session.
- **Audio:** volumes, per-app mixer and output devices, capture card inputs, now-playing controls, and locks that stop Windows switching devices.
- **Power:** game mode (fastest refresh rates while you play), nap time (screens off, PC stays on), device batteries.
- **Network:** speed test, ping/route test, and which apps are using the network.
- **Display:** arrange monitors, refresh rates, scale, brightness, per-screen wallpaper, saved layouts.
- **Storage:** what's using your drives, and safe clean-up.
- **Stats widget** for a side screen, keyboard shortcuts, and alerts when things run hot.

Windows 10 (2004 or later) or Windows 11, 64-bit.

This repository hosts the downloads.
